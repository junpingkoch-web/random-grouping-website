# Random Group Generator

A free, static (no build step) tool for randomly splitting a list of names
into groups — by target group count or by target group size. Trilingual UI:
中文 / English / Deutsch.

## Run locally

Just open `index.html` in a browser, or serve the folder with any static
server, e.g.:

```
npx serve .
```

## Structure

Single-file app: all HTML/CSS/JS lives inline in `index.html` (no separate
`style.css`/`script.js`) — see `CLAUDE.md`.
